## 功能缺口

- [ ] **retry 状态提示**：模型重试时界面没有反馈，看起来像卡住。
      监听 `session.retry.scheduled`，显示「第 N 次重试，X 秒后…」。
- [ ] **单实例锁**：双击多次会开多个窗口连同一个服务，容易出现重复权限弹窗和重复事件。
      用 `app.requestSingleInstanceLock()`，第二次启动时聚焦已有窗口。
