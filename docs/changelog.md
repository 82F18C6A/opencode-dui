# 更新记录

> 版本号与提交信息里的 `vX.Y.Z` 保持一致，`package.json` 的 `version` 同步更新。
> 只记录用户能感知的功能变化。

## v0.0.2

### 新增

- 长会话分页：消息区滚到顶部附近自动加载更早的 50 条，视口停在原位置
- 「回到最新」按钮：离开底部后右下角出现向下箭头，点击平滑回底
- 会话归档：会话行可归档，归档后从列表隐藏；「已归档」入口里能恢复或永久删除
- 会话重命名：双击标题就地编辑，Enter 保存、Esc 取消
- 删除工作目录：删除前提示会把该目录下的会话归档
- 右侧对话导航：常驻刻度显示提问位置，悬停展开问题列表，当前项高亮，点击跳转并在滚动结束后以呼吸灯效果高亮
- 工作目录前显示文件夹图标，新建会话按钮改为圆形描边加号

### 变更

- 侧边栏层级更明确：目录标题加背景色块并加粗，会话缩进显示
- 新建工作目录入口移到侧边栏顶部，移除顶栏的「新建会话」
- 模型选择移到输入框内、与发送键同一行；发送键改为圆形箭头图标
- 整体配色改为浅紫渐变

### 修复

- 用户消息靠右，与助手消息的内容列对齐
- 分页加载更早消息时，视口保持在原位置，不再跳到其他消息

## v0.0.1

初始版本：

- Electron 壳，复用官方 `opencode-cli` 服务，不改后端
- 自建 SolidJS 渲染层，浅色主题
- 会话列表与切换
- 消息三层渲染：推理折叠成行、工具调用独立卡片、答案白色气泡
- 流式增量（文本/推理 delta），其余事件防抖重拉
- 权限弹窗三档：拒绝 / 允许一次 / 总是允许
- 模型选择器，按 provider 分组，OpenRouter 默认只显示免费模型
- 新建会话，支持按工作目录分组的两级侧边栏
- 中断当前执行，运行中发送键变停止键
- 消息按时间正序显示，最新在底部
