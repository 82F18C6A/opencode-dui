# 更新记录

> 版本号与提交信息里的 `vX.Y.Z` 保持一致，`package.json` 的 `version` 同步更新。
> 只记录用户能感知的功能变化。

## v0.1.1

### 新增

- 图片输入：支持粘贴或拖入图片，输入区显示缩略图，消息里显示发送的图片，点击可看原图
- 网页预览：回答里的链接点击用系统浏览器打开，HTML 代码块右上角有「预览」按钮
- 中间步骤折叠：一轮里的思考和工具调用合并成一个折叠区，回复中展开，完成后折叠成「已完成，用时 N 秒」
- 提问回答记录：回答 agent 提问后，消息流里插入「你回答了：…」
- 启动时只展开当前会话所在目录，其余目录折叠
- 无会话的工作目录不再显示，新建工作目录时自动创建一个会话
- 会话标题实时更新

### 变更

- 整体配色改为更深的蓝紫渐变，侧边栏和顶栏同步加深
- 用户消息改为浅蓝紫，与背景区分
- 停止按钮改为灰色
- 输入框和问题卡片加宽到 860
- 中间过程里的结论文本收进折叠区，最终回答保持白底
- 每轮只显示一个「已完成」

### 修复

- 历史消息滚动到底部时被切成直线
- 失败的工具卡片默认展开
- 提问回答记录出现在最终回复后面
- 中间消息隐藏后留下空白

## v0.1.0

### 新增

- 代码块复制：每个 Markdown 代码块右上角有复制按钮，点击后提示「已复制」
- 上下文用量：输入框模型名右侧显示当前上下文占用和模型上限，例如 `128.7k / 200k`
- 服务重试提示：请求重试时显示错误原因、第几次重试和倒计时，成功后自动清除
- 归档全部删除：「已归档」里可以一次清空，删除前会确认
- 工作目录拖拽排序：目录可以拖动排序，整组会话跟随移动，顺序会记住
- 应用图标：紫色圆角图标，exe、窗口和任务栏统一
- 撤销消息：最后一条用户消息旁有撤销按钮，确认后回退对话并把原文填回输入框
- agent 提问：需要确认时输入区变成问题卡片，可点选选项或输入自定义答案，回答后 agent 继续执行

### 变更

- 模型选择按品牌过滤和排序：只保留 deepseek、glm、kimi、gpt、claude、gemini、qwen、mimo、minimax、longcat、grok；opencode 分为免费和付费两组，openrouter 只显示这些品牌的免费模型
- 错误提示条：额度/限流类常驻，网络类 5 秒后自动消失
- 撤销只回退对话，不再恢复文件改动

### 修复

- 撤销后对应的回答没有一起删除
- 会话的 Git 快照损坏时，撤销会返回 500
- 工作目录无法拖动到列表最上方
- 提问表单输入文字时被轮询刷新打断
- 多选提问缺少自定义输入入口
- 用户消息里的长文本（如没有空格的 SQL）超出气泡宽度

## v0.0.2

### 新增

- 长会话分页：消息区滚到顶部附近自动加载更早的 50 条，视口停在原位置
- 「回到最新」按钮：离开底部后右下角出现向下箭头，点击平滑回底
- 会话归档：会话行可归档，归档后从列表隐藏；「已归档」入口里能恢复或永久删除
- 会话重命名：双击标题就地编辑，Enter 保存、Esc 取消
- 删除工作目录：删除前提示会把该目录下的会话归档
- 右侧对话导航：常驻刻度显示提问位置，悬停展开问题列表，当前项高亮，点击跳转并在滚动结束后以呼吸灯效果高亮
- 工作目录前显示文件夹图标，新建会话按钮改为圆形描边加号

### 变更

- 侧边栏层级更明确：目录标题加背景色块并加粗，会话缩进显示
- 新建工作目录入口移到侧边栏顶部，移除顶栏的「新建会话」
- 模型选择移到输入框内、与发送键同一行；发送键改为圆形箭头图标
- 整体配色改为浅紫渐变

### 修复

- 用户消息靠右，与助手消息的内容列对齐
- 分页加载更早消息时，视口保持在原位置，不再跳到其他消息

## v0.0.1

初始版本：

- Electron 壳，复用官方 `opencode-cli` 服务，不改后端
- 自建 SolidJS 渲染层，浅色主题
- 会话列表与切换
- 消息三层渲染：推理折叠成行、工具调用独立卡片、答案白色气泡
- 流式增量（文本/推理 delta），其余事件防抖重拉
- 权限弹窗三档：拒绝 / 允许一次 / 总是允许
- 模型选择器，按 provider 分组，OpenRouter 默认只显示免费模型
- 新建会话，支持按工作目录分组的两级侧边栏
- 中断当前执行，运行中发送键变停止键
- 消息按时间正序显示，最新在底部
